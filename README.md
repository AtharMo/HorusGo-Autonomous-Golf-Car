# HorusGo – Autonomous Golf Car

## Overview

HorusGo is an autonomous golf car developed as a graduation project
for Horus University.

The system is designed to navigate the university campus autonomously
using computer vision, LiDAR, GPS, and ultrasonic sensors.

## Main Features

- Object detection using YOLOv8
- Lane detection using OpenCV
- GPS-based localization
- LiDAR-based environment perception
- Ultrasonic obstacle detection
- Real-time monitoring interface

## Technologies

- Python
- OpenCV
- YOLOv8
- PySide6
- LiDAR
- GPS
- Ultrasonic Sensors
